# Botanical interface pass

Audited against merged v0.26 (`75f7eea`), then rebased cleanly onto merged character PR #7 (`0360db5`). This commit contains only the UI changes.

## Audit and before/after

| Before | After |
| --- | --- |
| The opaque authentication gate obscured the title; the account form floated in a corner. | A branded botanical welcome screen pairs the title with a readable field-ID form, with a scrollable layout on short screens. Existing authentication handlers and validation remain in place. |
| Several generations of panel colors, sizes and tiny text competed for attention. | A shared token stylesheet defines forest/charcoal surfaces, copper accents, bioluminescent highlights, spacing, borders, typography and focus styles. |
| Collection descriptions, progression details and mission instructions occupied the combat view. | A compact HUD keeps vital numbers and current objectives visible. The J / Journal drawer contains the complete original collection, progression, objectives and minimap nodes. It works on PC and Android. |
| Backpack positioning inherited a translated center layout, which clipped when anchored to the right. | A bounded right drawer, responsive material cards, explicit close button, Escape handling and inert closed content. |
| Space on a menu button could also trigger melee; held movement could remain active on opening a panel. | Overlay opening clears held actions and releases mouse capture. Menu keyboard input is isolated from gameplay, with focus wrapping and restoration. I still closes the backpack. |
| Weapon and map panels shared inconsistent offsets; keyboard hints dominated the bottom edge. | Separate ammunition/map regions and a collapsible keyboard reference preserve the center view. Health and stamina keep both numbers and distinct bars. |
| Landscape phone enemy health was hidden. | A compact enemy bar remains visible during encounters. The original stick, FIRE-drag aiming, aim/run toggles and all action buttons remain available. |

## Implementation boundaries

- `src/styles/botanical.css` is the final design layer after the legacy component styles; its inclusion is covered by the stylesheet order/balance test. No dependency or generated art was added.
- `Interface.ts` manages presentation/focus only. Account API handlers, session cookies, save formats, networking, server rules, balance and graphics rendering code are unchanged.
- Journal panels are moved and restored rather than duplicated, retaining their IDs and gameplay handlers. Menus, journal and backpack close competing panels when opened.
- Focus rings, 40–44px form/action targets, textual vital values, reduced motion and increased-contrast preferences are supported. A software-keyboard or screen-reader audit on physical devices remains pending.
- Online font loading is inherited; system font fallbacks remain readable offline.

## Validation

`npm test`: 42 passing tests. `npm run typecheck` and `npm run build`: passed. The existing Vite bundle-size warning remains.

Browser fixtures use actual application HTML, CSS and panel/input classes, with account responses stubbed and gameplay simulation omitted. Chromium screenshots and assertions passed at 1920×1080, 1366×768, 390×844 and 844×390. Screenshots cover login, HUD, field menu, journal and inventory. Login Enter validation, menu focus, action suppression, held-input reset, journal node restoration, backpack close/inert state and viewport bounds passed without page errors. This does not measure GPU performance or prove full gameplay compatibility on a physical phone.

Repeat: start `npm run dev:client -- --port 5173`, then run `node tests/browser/interface.cjs` in an environment with Playwright and `/usr/bin/chromium`. Optional `GAME_URL` and `ARTIFACT_DIR` select the Vite URL and capture directory. Browser tooling is not a production dependency.

## Manual checklist

- Sign in/create account with mouse, Enter and Android keyboard; open account settings and save/logout after authentication.
- Move/fire/reload/heal with PC and Android controls; open each panel while moving and confirm input clears. Resume from the canvas.
- Join the same room with three PCs and one Android; check party count, co-op crafting and room exit.
- Open Journal with J, mouse and touch; expand collection details, track/select creatures, scroll to the map and close with Escape/button.
- Open/close Backpack with I and buttons; craft an available recipe; confirm costs and disabled states.
- Check injured/exhausted, reloading, enemy wind-up, damage/toast, defeat and extraction states against bright and dark scenery.
- Rotate the actual phone, open the software keyboard, and check safe areas, browser toolbar, 200% zoom, reduced motion and screen-reader focus order.

A separate live local-Worker check registered a local-only account, entered the actual 3D game at 1366×768, opened/closed the journal, switched to touch controls and resized to 844×390.
