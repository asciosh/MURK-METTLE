# Try the v0.22 graphics and animation update

Use the Cloudflare preview for the graphics/animation pull request, or check out its branch and run `npm ci`, `npm test`, then `npm run dev`. For a local preview open port 8787. Cloudflare branch previews use separate accounts from production, so create a test account if needed.

1. Enter the field. Walk with WASD and sprint with Shift. Check the shoulder/elbow, knee/boot movement and the lowered gun pose.
2. Use 1 and 2 to switch pistol/carbine. Hold RMB to aim, point up/down with the mouse, and fire with LMB. The rifle fires while held; the pistol needs individual clicks. Check that the hands remain near the grips and the tracer starts at the barrel.
3. Fire a few rounds and press R. Check the reload pose and magazine movement, and that reserve ammo decreases by the rounds loaded. The weapon must not fire during its reload.
4. Release the mouse with Escape, then open FIELD MENU. Under GRAPHICS try Balanced, Cinematic and Performance. Cinematic adds contact shading and needs more GPU power. Check vegetation cutouts remain clear rather than casting rectangular ambient-occlusion patches.
5. Look at the forest and settlement: grass blades, wind movement, connected twigs/leaves, new road material, doors/steps/downpipes and the distant ridgeline. These are original procedural assets, not photoreal scanned art.
6. Open the COLLECTION & EVOLUTION section in the companion card. The existing roster and selection still work. Press C to cycle owned creatures, and verify progress after saving/reloading.
7. Use two accounts in separate browser profiles to join the same room. Watch the other player walking, aiming, switching guns, firing and reloading. This pass synchronizes those visible poses; ammo and hits remain server-owned.
8. Check the shoulder camera near a solid building and tree. Its smoothed position should stay in front of the obstacle. Let an infected defeat you, observe the falling pose, then press R to restart.

After the preview works, mark the draft PR ready and merge it using the normal GitHub flow. With the existing integration, merging to main starts the production build. This change does not modify the Cloudflare bindings, migrations or preview setup added in the previous PR.

The next planned stages are multiple-zombie/survival gameplay, followed by more creature mechanics. Those features are intentionally separate from this visual update.
