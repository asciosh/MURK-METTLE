# v0.25 material provenance

All procedural geometry, foliage atlases, material generators and cloud shaders in this update are original project source. No generated model files, ZIPs or downloaded image binaries are added to GitHub.

The optional **Photographic surfaces** setting downloads twelve 1K JPEG maps (albedo, OpenGL normal and roughness for four surfaces), totaling 11,160,898 bytes before browser caching:

| Surface | Poly Haven source |
| --- | --- |
| Dirt/path | [Forest Floor](https://polyhaven.com/a/forest_floor) |
| Leaf litter | [Brown Mud Leaves 01](https://polyhaven.com/a/brown_mud_leaves_01) |
| Tree bark | [Bark Brown 01](https://polyhaven.com/a/bark_brown_01) |
| Weathered plaster | [Concrete Wall 006](https://polyhaven.com/a/concrete_wall_006) |

Poly Haven identifies its assets as **CC0** and permits commercial use and redistribution: [asset license](https://polyhaven.com/license), [CC0 summary](https://creativecommons.org/publicdomain/zero/1.0/). The website's non-asset content is not included.

`src/client/game/photo-surfaces.json` records each original URL, source page, license identifier, dimensions, byte count and a SHA-256 integrity value computed from downloaded source bytes. The browser verifies those hashes before decoding. Source files were inspected as JPEG images with maximum dimensions of 1024×1024. Maps remain hosted by Poly Haven's existing CDN; the game does not send account information to it (`credentials: omit`). The CDN still receives ordinary network request metadata.

Texture downloads are optional and load in the background. A complete three-map set is applied atomically per surface. Missing or rejected sets retain original procedural maps. Turning the setting off restores procedural maps and the lower resolution; downloads already started may finish and be cached in the current world instance. Disposing the world aborts outstanding requests and releases its caches. These are runtime references, not a vendored canonical asset package. External hosting availability and CORS policy can change; production should verify delivery from its own origin.
