# v0.20 acceptance and rollback checklist

## In Codespaces

1. Create a branch or commit your current working tree (`git status`).
2. Extract the ZIP over the repository root; confirm `package.json`, `src/main.ts`, `shared/coop-rules.mjs`, and `server/cloudflare/index.mjs` exist.
3. Run `npm ci`, `npm test`, `npm run build`.
4. Optionally start `npm run dev`; note the local Node WebSocket server does not provide authenticated cloud accounts. Use `npx wrangler dev` or a staging Worker for end-to-end login tests.
5. Run `npx wrangler deploy --dry-run --config wrangler.jsonc` and inspect bundled imports.

## In a staging Cloudflare deployment first, if possible

- Account: register (test username), log in/out, log back in, verify cloud save revision and successful reload.
- Navigation: title screen, FIELD MENU open/close, ESC, click-away, keyboard focus, account modal, PIN input without game keypress side effects.
- Solo: move, attack, loot, craft, Lanternkin bond/pulse/strain, mission beacon, death/restart; save and log in again.
- Co-op: two different accounts join `BLOOM`, see each other's characters and companions; try 4 participants. Verify shared combat, 3 kills, 2 samples, extraction, one-time rewards, inventory and trusted XP after relogin.
- Performance: check 1366×768, 1920×1080, 375×812; look for HUD overlap, scrollability, model loading and FPS stutters.
- Worker logs: verify no failed room/mission reward writes, no CPU-limit errors, and no unexpected 401/500 responses.

## Deploy only after gates pass

```sh
npm test
npm run build
npx wrangler deploy --config wrangler.jsonc
```

Versioning and commit message:

```sh
git add .
git commit -m "refactor: organize client, Cloudflare server and UI modules (v0.20)"
git push origin main
```

**Deployment reminder:** GitHub auto-deployment and a manual Wrangler deploy can target the same Worker. Make sure both use the v0.20 `wrangler.jsonc` and do not let a Pages-only pipeline overwrite the routed Worker.

## Rollback

1. If anything breaks, preserve logs and screenshots.
2. Deploy the last working commit's complete v0.19 Worker and assets; do not delete migrations or storage.
3. Investigate on a branch and re-run account and multiplayer acceptance checks before redeploying.
